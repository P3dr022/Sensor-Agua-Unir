# Sensor-Agua-Unir
Monitoramento remoto de nível de água em tempo real com ESP32 e Blynk — sensor de baixo custo baseado em transistores, dashboard mobile e projeto de IC/PIBITI (UNIR).

 Objetivos

 Objetivo Geral

Desenvolver e implementar o sistema de aquisição, processamento e transmissão de dados via ESP32, com dashboard remoto em aplicativo móvel para monitoramento de nível de água.

 Objetivos Específicos

- [ ] **Aquisição de dados** — Programar o microcontrolador ESP32 para leitura dos sinais dos quatro sensores baseados em transistores.
- [ ] **Comunicação** — Implementar a comunicação Wi-Fi e integração com a plataforma Blynk.
- [ ] **Interface** — Desenvolver e personalizar o dashboard interativo (gauge + LEDs virtuais).
- [ ] **Validação** — Realizar testes de transmissão, latência e confiabilidade da comunicação.
- [ ] **Documentação** — Criar material didático (código comentado e tutorial) para divulgação do projeto.
